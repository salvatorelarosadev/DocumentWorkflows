# Roadmap

This roadmap communicates direction, not a binding release commitment.

## Stage 0 — Repository standard
- Establish the reusable documentation hierarchy.
- Establish public-safe contribution and agent rules.
- Exercise the standard on a real subproject.
- Refine the model before propagating it to other repositories.

## Stage 1 — Markdown Document Engine
- Define a portable Markdown authoring baseline.
- Preserve semantic hierarchy independently from presentation.
- Implement Google Docs as the first renderer.
- Support automatic hierarchical section numbering.
- Support a usable TOC workflow.
- Add deterministic tests and examples.

## Stage 2 — Reusable document model
Subject to evidence and architectural approval:
- evaluate a renderer-independent internal document representation;
- formalize reusable style/configuration profiles;
- support richer semantic directives;
- separate parser, validation, and renderer responsibilities.

## Stage 3 — Additional renderers and integrations
Potential directions include Microsoft Word/Microsoft 365, TeX/LaTeX, HTML/PDF, direct Markdown workflows, and Scrivener interoperability.

## Stage 4 — AI-assisted editorial workflows
Potential directions include model-neutral authoring contracts, agent-readable document context, structural validation, editorial QA, and controlled multi-model drafting/review.
