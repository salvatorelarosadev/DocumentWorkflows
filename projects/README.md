# Subprojects

This directory contains independently scoped apps, engines, integrations, or workflow components developed within DocumentWorkflows.

Each substantial subproject should have its own:

- README.md;
- STATUS.md;
- ROADMAP.md when useful;
- CHANGELOG.md;
- VERSION when independently releasable;
- docs/ hierarchy using REQ, ARCH, ADR, RES, RFC, EP, RUN, and NOTE as applicable;
- src/, tests/, config/, examples/, templates/, scripts/, and lab/ as needed.
