# Code of Conduct

This project aims to be constructive, technically rigorous, and welcoming.

Contributors are expected to:
- discuss ideas and implementations rather than attack people;
- disagree with evidence and reasoning;
- give actionable review feedback;
- avoid harassment, discrimination, intimidation, and abusive behavior;
- respect privacy and never publish another person's private information;
- keep project discussions relevant.

Maintainers may moderate contributions or participation when necessary to protect the project and its contributors.

Technical criticism is welcome. Personal hostility is not.
